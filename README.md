# IronUniverse

Get all the components of Ironuniverse to become a true IronStar!

browser game where you control **YOU**, travel through different orbital rings, collect web-development elements, avoid dangerous planets and asteroids, and try to become a new **STAR**! ⭐

Your player is represented by **YOU** inside the universe.

Use the following keys:

| Key | Action       |
| --- | ------------ |
| `I` | Move inward  |
| `O` | Move outward |
| `S` | Stop         |

##  Lives

You start with **3 lives**.

Hitting dangerous planets or asteroids can cost you a life.

Use the **RESET** button to restart the game.

## Collectible Elements
* HTML
* CSS
* JavaScript
* Other web-development symbols

Your collected elements are displayed in the **Collected Elements** section.

## Tech stack

* **HTML5** – Game structure
* **CSS3** – Styling, animations and space-themed UI
* **JavaScript** – Game logic, movement, collisions and interactions


## Game Concept

The idea behind is to combine a space adventure with web development concepts.

Instead of collecting ordinary objects, the player collects web elements while navigating through a universe filled with bugs and obstacles.

> Collect the elements. Avoid the bugs. Become the STAR.
